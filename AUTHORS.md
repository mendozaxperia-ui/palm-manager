# Project stewardship and AI-assisted development

**Project maintainer:** [@mendozaxperia-ui](https://github.com/mendozaxperia-ui).

**Development method:** Palm Manager was developed through human-directed, AI-assisted programming (often called *vibe coding*). OpenAI ChatGPT was used extensively to propose architecture, write and modify code, produce documentation, and help debug the USB and Bluetooth connection. The human maintainer requested features, chose the project's direction, operated and tested the Palm Tungsten T3, inspected the results, and decided to publish the project.
